# Login Page UI
A simple login page interface created using HTML and CSS.
## Features
* Animated gradient background
* Glassmorphism-style login card
* Mobile number input
* Password input
* Login button
* Services section
* Responsive layout
* Hover effects
## Technologies Used
* HTML5
* CSS3
## Project Structure
login-page/
├── Project.html
├── README.md
├── screenshots/
│   └── login-page.png
└── demo/
    └── login-page-demo.mp4
## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `Project.html` in a web browser.
4. The login page will appear.
No additional installation or dependencies are required.
